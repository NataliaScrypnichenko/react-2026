спочатку в файл додаємо  package.json
"dependencies": {

"react-router-dom": "^7.0.2"
},
 відкриваємо файл main.tsx 
і там заміняємо <APP/> => <RouterProvider router={}/> роутер приймає аргументи в якості якогось значення
=ці значення це шляхи за якими будемо переходити тобто це мапа за яку урлу вбраузері який компонент буде відповідати і кого буде потрібно в цьому місці показувати

Після того як прописали шляхи в main то створюємо MainLayout в паці layouts яка знаходиться в src
